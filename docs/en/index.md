# Reticulum-Go

Reticulum-Go is a Go implementation of the [Reticulum Network Stack](https://reticulum.network/). It speaks the same wire protocol as the Python reference implementation and interoperates with Python nodes on the same network.

Use these documents to integrate, operate, or extend the stack.

## Where to start

- New to the project: read the [overview](overview.md), then [getting started](getting-started.md).
- Writing a Go application: [API reference](api-reference.md) and [examples](examples.md).
- Running a node: [configuration](configuration.md) and [interfaces](interfaces.md).
- Comparing with Python RNS: [compatibility](compatibility.md) and [deviations](deviations.md).
