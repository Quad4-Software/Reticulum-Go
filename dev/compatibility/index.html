Compatibility with Python Reticulum¶

Reference target¶

Reticulum-Go is tested against Python RNS 1.6.1, plus the official network API reference.

Crossref vectors clone the reference from rns://7649a50d84610232d1416b41d2896aff/reticulum/reticulum via rngit (tests/crossref/run_crossref.sh). The GitHub mirror is not used for vectors.

The detailed matrix with config key tables lives in COMPATIBILITY.md. This page summarizes the key differences and design choices.

UDP requires explicit target_host or target_address (Python forward_ip policy).

Opt-in UDP reconnect when max_reconnect_tries > 0 is a Go extension.

Opt-in keepalive = <seconds> on UDPInterface is a Go extension. It emits a one-byte hold-open datagram while idle (NAT binding keepalive). Peers drop it at decode, so it is safe to enable against Python endpoints.

Reconnect backoff carries jitter and reconnects kick early on underlay network changes (Linux rtnetlink). Both are local timing behavior only. No wire changes.

Known gaps¶

Gap Impact
Discovery TCPClient/I2P autoconnect Go implements TCP client and I2P peer autoconnect from discovery. Python still stubs these paths
Remote management mutate Remote /path table and rates plus /status work. Remote drop, path-request, and blackhole mutate are unimplemented (Python also exits 255)
RNode and radio serial drivers RNodeInterface and RNodeMultiInterface with KISS framing are present (serial and tcp://). Generic KISSInterface, AX25KISSInterface, and WeaveInterface are not in this tree. SerialInterface, Modem73Interface, and SDRInterface are present
Utilities rnir rnpkg Not ported
rngit Ported (reticulum-go git, git-remote-rns)
Python-only utilities rnir, rnpkg, rnodeconf are not ported

Verification workflow¶

# Unit and package tests
make test

# Crossref against Python vectors
./tests/crossref/run_crossref.sh all

# Live Go/Python side by side
RUN_LIVE_INTEROP=1 go test -v ./tests/interop/...

Running alongside Python¶

Use separate config directories (~/.reticulum-go vs ~/.reticulum). Point interfaces at the same peers with matching IFAC and ports. Shared instance ports must not conflict if both try to own the same interface.

To let rgostatus query Python rnsd, point -config at ~/.reticulum and align rpc_key when set. On Linux both stacks default to Unix RPC when shared_instance_type is unset. Go tools also fall back to TCP when the type is unset. See CLI utilities.
