# Contributing

Reticulum-Go is a high-security implementation. As such, all contributions must be submitted as `.patch` files, preferably over Reticulum LXMF. We will then review and test each submission thoroughly, which can take several days.

## Commit Requirements

To maintain the integrity, security, and legal clarity of the project, all commits in your `.patch` files must:
1. Include a **Signed-off-by** line (`git commit -s`) as explicit agreement to the CLA below.
2. Be cryptographically signed using GPG (`git commit -S`).
3. Include your proper, working email address in both the Git author field and the GPG signature.

You can do both signing operations at once with: `git commit -s -S`
