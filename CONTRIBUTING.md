# Contributing

Contributions are welcome. Prefer sending changes as `.patch` files over Reticulum LXMF when you can. Pull requests and email are also fine. Reviews may take a few days.

## Commit Preferences

To keep authorship clear and make review easier, please try to:

1. Sign commits with GPG or SSH when practical (`git commit -S`).
2. Use a real email address or LXMF address in the Git author field.
